# ntnu-math-2026-quadratic-lab

國立臺灣師範大學數學系「數學教學實習(一)」115-1 預習試教使用的互動平台。
範圍：康軒版國中數學 第 1 章 1-1，主題 1「二次函數的意義」、主題 2「二次函數 y = ax² + k 的圖形」。

- **互動專區**：描點變曲線、拉桿實驗室（a、k）、對摺工具（搭配學習單）
- **測驗區**：分關卡隨機出題（開發中）

純前端（HTML、CSS、JavaScript ES modules），部署於 GitHub Pages；之後會接 Supabase 處理登入、老師端控制與即時統計。

本機預覽：在此資料夾執行 `python -m http.server`，開啟 http://localhost:8000/
